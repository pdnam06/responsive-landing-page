# Responsive Landing Page

Landing Page responsive được xây dựng bằng HTML và CSS:

- Header và menu điều hướng dùng Flexbox.
- Hero section dùng CSS Grid.
- Danh sách dịch vụ dùng Flexbox và `flex-wrap`.
- Khu vực quy trình và đánh giá dùng CSS Grid.
- Media Queries tối ưu cho tablet và điện thoại.
- Không có hiện tượng tràn ngang trên màn hình nhỏ.

Mở `index.html` bằng trình duyệt để xem kết quả.
